disable-model-invocation: true
---
Запит користувача: $ARGUMENTS.

1. Прочитай status і diff, збережи наявні сторонні зміни; не додавай файли навмання.
2. Перевір, які тести вже пройшли, та запусти лише необхідні відсутні перевірки.
3. Вибери конкретні шляхи для staging. Не використовуй git add . без перегляду всіх файлів.
4. Запропонуй коротку назву, що описує кінцеву зміну, і виконай команди з підтвердженням.
5. Не виконуй push, force push, reset або amend без окремого явного запиту користувача.

# Стан реалізації Medfarl AI System

Оновлено: **2026-10-24**. Це поточний знімок реалізації, не оголошення нового релізу.

## Режими

| Режим | Запуск | Призначення |
| --- | --- | --- |
| Чат | `run.bat` | Потокова розмова без інструментів |
| Кодер | `run-coder.bat`, пункт 19 або `/coder` | Файли, проєкти, перевірки та розширення |
| Планування | `--coder --plan` або `/plan` | Дослідження без запису, shell, hooks і MCP-викликів |
| Діагностика | `run.bat --agent`, пункт 18 | Телеметрія, пакети, процеси, мережа й обслуговування |
| Diagnostic unsafe | `run-unsafe.bat` | Старий режим діагностики з розширеними правами без підтверджень дій |

Типова модель: `tripolskypetr/qwen3.5-uncensored-aggressive:4b`.
Ollama може запускатися й попередньо завантажувати встановлену модель.
Моделі автоматично не завантажуються з інтернету.

## Реалізовано в кодері

- Створення файлів, папок і багатофайлових проєктів; шаблони Python, web та empty.
- Точкові зміни й повний перезапис із поточною контрольною сумою.
- Пакети до 32 файлів, 512 KiB на файл, 2 MiB загалом; diff і перевірка конфліктів.
- Пошук, читання з номерами рядків і фіксовані Git status/diff/log.
- Запуск команд у вибраній підпапці після підтвердження.
- Сім оригінальних скілів і завантаження власних `SKILL.md`.
- Планування зі списком задач та перевіркою дозволених інструментів у runtime.
- Проєктна пам’ять, CLAUDE-вказівки й правила за шляхами.
- Явне збереження/відновлення сесій і стискання історії.
- Контрольні точки й відкат файлових правок зі збереженням зовнішніх змін.
- Послідовні агенти для окремого аналізу без права запису чи запуску команд.
- MCP stdio та HTTP JSON/SSE; command hooks PreToolUse/PostToolUse.
- Одноразові завдання через `--prompt`, вибір моделі та огляд конфігурації.

Кодер зберігає підтвердження дій навіть після розширення файлового доступу.
Shell і процеси MCP не ізольовані від прав користувача ОС. Серверна авторизація,
OAuth, IDE/LSP, хмарні функції та повна семантика Claude plugins не реалізовані.

## Підтверджені перевірки

Автоматичний набір: **80 тестів — 79 пройшли, 1 пропущено**.
Тест символічних посилань пропущено через обмеження поточного користувача Windows.

Ручні перевірки підтвердили виклики інструментів Qwen 9B, створення проєкту,
редагування README, тести згенерованого Python-проєкту, планування без запису,
відновлення сесії, команди термінала та локальний MCP echo-сервер.
HTTP JSON/SSE перевірено через mock transport; зовнішні сервери з автентифікацією
не перевірялися. Результати не означають перевірки всіх ОС чи моделей.

```powershell
python -m unittest discover -s tests -v
```
